# Simon Game (jQuery)

A classic Simon memory game built with **HTML, CSS, JavaScript, and jQuery**.  
Repeat the color + sound sequence — it gets longer every level.

## Live Demo
- https://<your-username>.github.io/Simon-Game/

## Features
- Random sequence generation (new step each level)
- Click + sound feedback
- Level tracking
- Game over + restart

## Tech Stack
- HTML
- CSS
- JavaScript
- jQuery

## How to Play
1. Start the game (press any key / click start — depends on your implementation).
2. Watch the pattern.
3. Repeat the pattern by clicking the buttons in the same order.
4. Keep going — one new step is added each round.

## Run Locally
1. Clone the repo:
   ```bash
   git clone https://github.com/dorhaboosha/Simon-Game.git
   ```
2. Open `index.html` in your browser (or use VS Code Live Server).

## Project Structure
- `index.html` – UI structure
- `styles.css` – styling
- `game.js` – game logic
- `sounds/` – sound effects
